# NovaCalc – Smart Calculator

## About the Project
NovaCalc is a modern and responsive calculator developed using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship 2026.

## Features
- Addition, subtraction, multiplication and division
- Percentage calculation
- Decimal number support
- Clear All (AC) functionality
- Delete (DEL) functionality
- Positive/Negative number toggle
- Modern dark-themed user interface
- Blue and purple gradient design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or your browser.
4. Start performing calculations.

## Project Structure
- index.html – Calculator structure
- style.css – Calculator design and styling
- script.js – Calculator functionality
